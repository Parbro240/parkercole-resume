# Parker Cole Engineering Portfolio — Deployment Guide

This folder is ready to publish as a static website. The important requirement is that `index.html` stays at the top level of the published folder/repository.

## Recommended: GitHub Pages
1. Create a GitHub repository for the portfolio.
2. Upload **the contents of this folder** so `index.html`, `project.html`, `css`, `js`, and `assets` are at the repository root.
3. In the repository, open **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select the `main` branch and `/(root)`, then save.
6. GitHub will provide a public HTTPS URL. Future edits pushed to `main` will republish automatically.

## Fastest: Netlify Drop
1. Sign in to Netlify.
2. Open Netlify Drop.
3. Drag this entire folder into the upload area.
4. Netlify will publish it and provide a public `netlify.app` URL.
5. To update the site later, edit the local files and drag the updated folder into the site's deploy area again.

## Before publishing
- Confirm the phone number, email address, LinkedIn URL, and resume are the exact versions you want public.
- Only publish Peterbilt material you are authorized to share publicly.
- Test the final public URL on both a phone and a computer.
