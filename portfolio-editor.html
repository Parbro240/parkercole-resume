Publish your changes

When you are done editing, download the updated data file or copy the generated text. Your live site updates after you replace portfolio-data.js in GitHub and commit the change.

  1. Download portfolio-data.js.
  2. In GitHub, open your portfolio repository and open portfolio-data.js.
  3. Click the pencil icon to edit.
  4. Select all existing text and replace it with the generated text below (or the downloaded file's contents).
  5. Commit the change. GitHub Pages will redeploy automatically.
