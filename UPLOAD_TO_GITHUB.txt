PARKER COLE PORTFOLIO - EDITABLE GITHUB PAGES BUILD
=================================================

Upload the CONTENTS of this folder to the ROOT of your GitHub Pages repository.

Required top-level files:
- index.html
- project.html
- portfolio-data.js
- portfolio-editor.html
- Parker_Cole_Resume.pdf
- Parker_Cole_Resume.docx
- .nojekyll
- images/ (folder)

After upload, index.html should be visible immediately on the repository's main Code page.

To edit later, read HOW_TO_EDIT_WEBSITE.md and use portfolio-editor.html.
